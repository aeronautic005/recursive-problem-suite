# Recursive Problem Suite & Maze Pathfinder

An advanced Object-Oriented Java suite implementing fundamental and complex recursive algorithms, mathematical sequence generators, recursive backtracking, and custom recursion domain exceptions.

## Project Status: Milestone 1 (Foundation & Math Engine) [In Progress]

- [x] **Milestone 1: Domain Exceptions & Recursive Mathematical Engine**
  - Custom exceptions (`InvalidRecursionInputException`, `RecursionLimitExceededException`)
  - Pure recursive implementations: Factorial, Exponentiation, Sum of Digits, Pell Sequences
  - Call stack limit safeguards & boundary validation
- [ ] **Milestone 2: String & Palindrome Recursive Processing** *(Coming in Part 2)*
- [ ] **Milestone 3: 2D Maze Grid Representation & Backtracking Pathfinder** *(Coming in Part 2)*
- [ ] **Milestone 4: Interactive Visual CLI & Performance Benchmark Hub** *(Coming in Part 2)*

## How to Compile & Run (Milestone 1)

```bash
# Compile all files
javac *.java

# Run test suite
java RecursionApp
```
